## 是什么 / 什么时候用
Design Spells 收集真实产品里"有魔法感"的设计细节：微交互、彩蛋、拟物、节日限定动画、404 小游戏等。每条（spell）= 一段 5~20 秒的 mp4 录屏 + 一句英文标题（标题本身就是交互描述）+ 来源产品 + 标签，没有代码、没有长文说明。
适用场景：想给按钮、点赞、下拉刷新、开关、空状态、404 页、引导页、加载等待、节日活动加"惊喜感"时，先按标签/关键词在清单里找真实产品的参考做法，再看视频逐帧复刻。不适合直接拿组件代码——需要代码时配合 shadcn/动效类组件库实现。
共 340 条（Spell 001–340，2026-10-04 最新），19 个标签，全部免费；站点另有双周 newsletter（Spells Digest，77 期）。

## 按需获取方法
站点是 TanStack Start SPA，部署在 Vercel，**命令行 curl 一律被 Vercel Security Checkpoint 拦截（429 + JS challenge）**；没有 sitemap / llms.txt / robots 可用。但 **视频 CDN `cdn.designspells.com` 不设防，curl 可直接下载**。因此：

1. **查条目**：直接用本文件下方清单 / `designspells.tsv`（含编号、标题、产品、标签、视频文件名、中文描述）。按标签或中文关键词 grep：
   ```bash
   grep -i '下拉刷新\|pull-to-refresh' ~/.claude/skills/ui-arsenal/sources/designspells.tsv
   awk -F'\t' '$4 ~ /easter-egg/' ~/.claude/skills/ui-arsenal/sources/designspells.tsv
   ```
2. **看效果（复刻的唯一依据）**：下载视频后逐帧看。
   ```bash
   curl -sL -o /tmp/{file} https://cdn.designspells.com/videos/{file}          # 例：videos/arc.mp4（实测 200, video/mp4, 143KB）
   curl -sL -o /tmp/{base}.jpg https://cdn.designspells.com/first-frames/{base}-first-frame.jpg   # 首帧静态图，{base}=文件名去掉 .mp4
   # 抽帧给模型看：
   ffmpeg -i /tmp/{file} -vf fps=4 /tmp/{base}-%03d.png
   ```
   `thumbnails/{base}-thumbnail.jpg` 只是几百字节的模糊占位图，别用。
3. **详情页**（人看）：`https://designspells.com/spells/{slug}`，slug 中的 `"`、`'` 需 URL 编码（实测 `/spells/%22eat-this-playlist%22-snake-minigame-on-spotify` → Spell 045）。详情页只有标题、产品名、标签和视频，没有额外文字说明。产品聚合页：`/apps/{appSlug}`。
4. **在浏览器里拿最新全量数据（新增条目时用）**：需要真实浏览器先通过 Vercel challenge（内置浏览器 / Chrome 打开 https://designspells.com/ 即可），然后在页面里执行：
   ```js
   // list spells: GET /_serverFn/<id>?payload=<seroval>, header x-tsr-serverFn: true；每页 20 条，用 nextOffset 翻页
   const ID='0f6ace9f1eb388527bcea3e9cd96f5834ae5aa2a79ea6c4581cf11bb4a38c975';
   const enc=(tag,skip)=>({t:10,i:1,p:{k:['tagSlug','skip'],v:[tag?{t:1,s:tag}:{t:2,s:1},{t:0,s:skip}]},o:0});
   const dec=n=>!n?n:n.t===0||n.t===1?n.s:n.t===2?[null,undefined,true,false][n.s]:n.t===9?n.a.map(dec):n.t===10?Object.fromEntries(n.p.k.map((k,i)=>[k,dec(n.p.v[i])])):null;
   ```

5. 依赖：无（只是参考视频）。复刻时常用 motion / CSS keyframes / canvas / three.js，按效果自行选型。

## 使用注意
- 没有代码、没有实现说明，复刻全靠看视频：先抽帧确认时序、缓动（弹性/回弹/惯性）、触发条件（hover/长按/拖拽/滚动阈值/特定输入），再实现。
- 标题即描述，部分标题在数据库中带转义引号（如 `\"Printing\" animation...`），本清单已还原为正常引号。
- 平台标签 mobile/desktop/tablet 决定交互语境：mobile 多为手势、陀螺仪、灵动岛（Dynamic Island），desktop 多为 hover、光标、键盘彩蛋；移植到 Web 时需要换触发方式。
- 节日类（occasion）、品牌彩蛋类（easter-egg）多依赖特定上下文，做产品时挑"机制"借鉴，不要照搬品牌元素。
- 视频是第三方产品录屏，版权归原产品，不要把视频/截图直接放进交付物。
