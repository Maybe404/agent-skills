# 宿主扩展

宿主是运行本会话（编排者）的工具。SKILL.md 只写能力，每个宿主扩展把这些能力翻译成该宿主的具体工具。启动时确认自己运行在哪个宿主里，读对应的扩展文件。

## 宿主能力清单

每个宿主扩展都要回答下面这些问题。新增宿主时，复制本节的标题逐项填写，实测过的标"已验证"。

1. **向用户提问**：有没有结构化的选项提问工具。
2. **宿主 subagent**：怎么派一个新上下文的子 agent；能选哪些模型；怎么续接；并行时怎么隔离（worktree）；权限能不能比本会话更窄。用户没选 worker 时，它就是默认 worker。
3. **后台运行**：怎么在后台跑外部命令，完成后怎么收到通知，避免轮询。
4. **内置审查**：有没有现成的代码审查、安全审查命令。
5. **loop 与定时任务**：有哪些持续运行或定时运行的方式，各自能不能调用本机的 CLI 和文件。
6. **调用参数**：用户调用本 skill 时附带的任务描述怎么传进来。
7. **已知的坑**。

## 没有对应扩展时

按通用方式执行，并在第一行状态提示里告诉用户"这个宿主还没有扩展"：

- 提问：用文字列出编号选项，请用户回复编号。
- 宿主 subagent：宿主没有子 agent 能力时，不能把它当默认 worker；请用户选一个外部 worker，不要由本会话自己实现。
- 后台运行：宿主不支持时，前台运行并设置足够长的超时。
- 审查：用审查者 worker 按 [../gates.md](../gates.md) 的输出格式审查。
- loop：只做单次任务，告诉用户这个宿主不支持 loop。
